# 概要
このプロジェクトではtmuxとterminalをつかって次のようにマルチエージェントで深い思想をめぐらすようにしたい。

1. Orchestrator - 指揮者(総括役兼Humanとのコンダクタ)
2. Worker1 - 作業者(claude code opts)
3. Worker2 - 作業者(codex 5.5 high)
4. Worker3 - 作業者(claude code sonnet)

実行したタイミングでterminalが新規で立ち上がりそこで作業を実施する

## 画面構造
--------------------------------------------
|                      |                    |
|   orchestrator       |    worker1         |
|                      |                    |
--------------------------------------------
|                      |                    |
|                      |     worker2        |
                      -----------------------
|                      |                    |
|     human            |                    |
|                      |     worker3        |
|                      |                    |
---------------------------------------------

## 仕様
- humanが入力するとorchestratorがその入力を受け取り、worker1, worker2, worker3に順番にタスクを割り当てる.
- 初回立ち上げ時にinitコマンドを実行して、設定ファイルを立ち上げる。
- 各workerの設定を記載することが可能である。
- 提供はCLIとする。
